# 拒否コマンド一覧（pre-tool-guard.ps1 が読む）
#
# Bash / PowerShell ツールのコマンド文字列がここのパターンに一致したら、
# PreToolUse フックが実行前に拒否する（CLAUDE.md 絶対ルール4「破壊的操作は
# 必ず確認」の機械化）。
#
# 書き方:
#   - コマンド文字列の **部分一致** （どこかに現れれば一致）
#   - 使えるワイルドカードは * のみ（それ以外は文字どおり）
#   - 空行と # で始まる行は無視される
#
# 拒否されてもユーザー自身は実行できる。必要な操作が止まったら、
# ユーザーが手で実行するか、この一覧から外す。

# 履歴・作業ツリーの破壊
git reset --hard*
git checkout -- *
git clean -*f*

# リモートの破壊
git push*--force*
git push*-f *

# 検証の迂回
git commit*--no-verify*

# ファイルの一括削除
rm -rf *
Remove-Item*-Recurse*-Force*
