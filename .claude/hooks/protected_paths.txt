# 保護パス一覧（pre-tool-guard.ps1 が読む）
#
# ここに書いたパスへの Write / Edit / NotebookEdit を PreToolUse フックが
# 拒否する。CLAUDE.md プロファイルの「凍結文書」と、生成物・機密ファイルを
# 機械的に守るための一覧。
#
# 書き方:
#   - リポジトリルートからの相対パス（先頭一致）
#   - 使えるワイルドカードは * のみ（それ以外は文字どおり）
#   - 空行と # で始まる行は無視される
#
# 例:
#   docs/Note/            ディレクトリ配下すべて（凍結文書）
#   docs/generated/*.md   生成された Markdown
#   *.lock                任意の場所のロックファイル（先頭の * が任意の階層を吸収する）
#
# 注意: 拒否は「エージェントが編集できない」だけで、ユーザー自身の編集は
# 妨げない。誤検出したらこの一覧を直す。
#
# ---- 以下を、このプロジェクトの保護対象に置き換える ----
