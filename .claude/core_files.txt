# 「core 無変更」の検査対象一覧（check_unchanged.py が読む）
#
# CLAUDE.md 家風パターンの「core 無変更」を機械検証するためのファイル。
# 中核（実行機構・契約・その薄い利用側）に手が入っていないことを、
# フェーズごとに次のコマンドで確認する:
#
#   <プロファイルの「.claude/tools/ の Python ツール実行」コマンド>
#       .claude/tools/check_unchanged.py --since <フェーズ開始コミット>
#
# 書き方:
#   - 1 行 1 パス（リポジトリルートからの相対パス）
#   - 空行と # で始まる行は無視される
#   - 存在しないパスを書くとエラーになる（誤って「無変更」と報告しないため）
#   - 対象が 0 件でもエラーになる（空振りの検査を成功と報告しないため）
#
# 何を載せるか:
#   - 拡張の継ぎ目である契約（実装を足す側であり、契約自体は変えない）
#   - 中核の実行機構（機能の種別が増えても変わらないはずのもの）
#
# 1 ファイルでも差分が出たら、拡張の仕方が「契約の実装を足して
# Composition Root で差し替える」形になっていない。
#
# ---- 以下を、このプロジェクトの中核ファイルに置き換える ----

# 契約（拡張の継ぎ目。実装を足す側であり、契約自体は変えない）
# src/<pkg>/domain/contracts.py
# src/<pkg>/domain/<contract>_factory.py

# 実行機構（フェーズをまたいで無変更であるべきもの）
# src/<pkg>/domain/<core_mechanism>.py
# src/<pkg>/application/<core_usecase>.py
