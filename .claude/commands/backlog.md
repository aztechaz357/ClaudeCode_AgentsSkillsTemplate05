# バックログ（進捗と優先順位の正）

**引数（任意）:** `init`（新規作成）/ `status`（現在地の報告）/
`次`（次の一手を決める）/ 自由記述（スライス・負債の追加）。
省略時は `status` として扱う。

`docs/backlog.md` が **進捗と優先順位の唯一の正** 。
成熟度の定義と完了条件は `.claude/skills/agile-process/maturity.md` を参照する。

## モード: init（バックログの新規作成）

1. `docs/concept.md` を読む。無ければ `Skill('concept-definition')` で
   **ゴールと完走の定義だけ** を先に確定させる（全部埋めなくてよい）
2. `.claude/skills/agile-process/backlog-template.md` を写して
   `docs/backlog.md` を作る
3. 典型シナリオを **縦切りスライスに割る** 。判定は
   `Skill('agile-process')` の「縦切りスライス」節:
   - 入口と出口が 1 本に入っているか（層で切っていないか）
   - 半日以内に L1 に到達する量か
   - **割り方は `Skill('option-first')` で 3 案出して選んでもらう**
     （どのモードでも 1 回は聞く。 `伴走` では必ず）。
     3 案は「粒度の違う切り方」にする ——
     細かく多く / 推奨 / 大きく少なく。各案に
     **「選ばないとどうなるか」**（最初に動くものが見えるまでの距離・
     途中で方針転換できる回数）を書く。
     **スライスの切り方はここでしか学べない** —— 以降の反復は
     もう切られた後の作業になる
4. S01 は **最も薄い経路**（骨組み）にする。以降を価値と依存で並べる
5. 全スライスを `L0 未着手` で置き、コミットする（接頭辞 `docs:`）

スライス数の目安は **3〜8 本** 。それより多いならゴールが大きすぎるので、
`docs/concept.md` のゴールを分割してユーザーに確認する。

## モード: status（現在地の報告）

Tool で確認してから報告する（記憶で答えない）。

1. `docs/backlog.md` を読む
2. `git log --oneline -10` と、プロファイルのテストコマンドで現状を確認する
3. 要求（`docs/usdm/src/`）とスライス文書（`docs/slices/`）の実在と
   成熟度表記がバックログと一致しているか確認する。
   食い違ったら **実物を正として直す**

報告形式:

```markdown
## 現在地

- ゴール: {一行}
- 骨組み: {通った（S01・日付）/ 未着手}
- 成熟度: L1 {n} 本 / L2 {n} 本 / L3 {n} 本 / L0 {n} 本
- 着手中: {S## または なし}
- 負債: {n} 件（痛み高 {n} 件）
- テスト: {passed / skipped}

## 次の一手

{1 つだけ提示する。根拠は maturity.md の PM ルール}
```

## モード: 次（次の一手を決める）

`maturity.md` の「プロジェクト全体の進め方（PM ルール）」表に **機械的に**
当てはめる。その場の創意で順序を変えない。

| 状況 | 次の一手 |
|---|---|
| 骨組みが L1 未満 | `/skeleton` |
| L0 のスライスが残っている | `/iterate S##`（最上段の L0） |
| 全スライスが L1 で、負債が反復 2 回分たまっている | `/refactor` |
| 全スライスが L1 | `/iterate S##`（価値の高い順に L2 へ） |
| 全スライスが L2 で、他人に渡す | `/refactor`（L3 へ） |
| 全スライスが L2 で、渡さない | **完成** 。次のゴールを `/backlog init` で立てる |

提示は **1 つだけ** 。「あれもこれも」は WIP = 1 の原則に反する。

## モード: 自由記述（スライス・負債の追加）

1. 追加要望が **今回のゴールに寄与するか** を `docs/concept.md` で判定する
   - 寄与しない → 「今回のゴールの外」表に降ろし、理由を書く
   - 寄与する → スライス表に追加し、価値と依存を決める
2. 「手抜きを見つけた」という内容なら負債表へ（`D##` を採番。痛みと返す条件を書く）
3. 既存スライスと重複していないか確認する（重複は統合する）
4. コミットする（接頭辞 `docs:`）

## 禁止事項

- 着手中のスライスを 2 本以上にする（WIP = 1）
- 骨組みが通る前に L2 以上の作業を積む
- バックログを更新せずに反復を進める（状態を会話に置かない）
- 成熟度を「たぶん上がった」で更新する（テスト結果と実行出力で確認する）
