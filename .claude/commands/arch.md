# アーキテクチャの現在地と乖離

**引数（任意）:** `diff`（既定。設計との差）/ `actual`（実物の図だけ）

規約の正は `.claude/skills/architecture-drift/SKILL.md` 。
ソースルートと Python 実行コマンドは **プロファイルの値** を使う（推測しない）。

## モード: `diff`（引数なしのとき）

1. 実物の図と設計との差を作る:

   ```
   <ツール実行コマンド> .claude/tools/diff_arch.py <ソースルート>
   ```

2. 終了コードで分岐する:

   | 終了コード | 意味 | やること |
   |---|---|---|
   | 0 | 乖離なし | 1 行で報告して終了 |
   | 1 | 乖離あり | 下の形で報告する |
   | 2 | 比較できない | 原因（図が無い / Python でない）を伝える。 **「乖離なし」と言わない** |

3. 報告（6 行以内）:

   ```
   構造: {n} モジュール / {n} 依存
   一致 {n} 本 / 未実装 {n} 本 / **実装にだけある {n} 本** / 逆流 {n} 本
   実装にだけある: {a → b}（{妥当そうか・逸脱そうか 1 行}）
   逆流: {a → b}
   図: docs/architecture-diff.md
   次の一手: {設計書に追記 / 実装を戻す / 負債に記録 / なし}
   ```

4. **黄色（実装にだけある）を 1 本ずつ判定する** 。
   妥当なら設計書へ追記、逸脱なら実装を戻す。戻せないなら負債表へ。
   **全部を「設計書に追記」で片づけない**（設計の後追い正当化になる）

## モード: `actual`

```
<ツール実行コマンド> .claude/tools/build_arch.py <ソースルート>
```

実物の依存図（`docs/architecture-actual.md`）だけを作る。
設計書がまだ無い骨組みの段階や、既存コードを引き継いだ直後に使う。

## 成熟度で基準が変わる（超えて作業しない）

| 目標 | 逆流 | 実装にだけある | 未実装 |
|---|---|---|---|
| L1 | 記録すれば可 | 記録すれば可 | 可 |
| L2 | 0 件 | 3 本まで（記録） | 可 |
| L3 | 0 件 | 0 件 | 0 件 |

**L1 の反復で乖離を 0 にしにいかない。** 記録されない乖離だけが違反。

## やってはいけないこと

- 生成物（`architecture-actual.md` / `architecture-diff.md`）を手で編集する
- 終了コード 2（比較できない）を「乖離なし」と報告する
- 目標が L1 のスライスで乖離の解消を始める
- このコマンドの中で実装を直す（直すのは `/refactor` か次の反復）
