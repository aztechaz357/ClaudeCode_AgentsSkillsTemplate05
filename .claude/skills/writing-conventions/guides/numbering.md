# 数式・図・表の記法と番号

要求仕様書・設計書に数式を書くときは、 **読みにくい数式は許可しない。**

## 数式は必ず TeX で書く

- インライン数式は `$...$`、独立した数式は `$$...$$` で書く
- **アスキーアート・プレーンテキストによる数式は禁止** 。
  `sqrt(2/3)` `x_i` `[a b; c d]` のような書き方をしない。
  それぞれ $\sqrt{2/3}$ 、 $x_i$ 、`\begin{bmatrix}` を使う
- 行列・ベクトルは `\begin{bmatrix}...\end{bmatrix}` を使う
- 添字は `_`、上付きは `^` を使う（ $x_i$ 、 $\theta$ 、 $x_i^2$ ）
- ギリシャ文字は `\alpha` `\beta` `\theta` `\sigma` `\omega` などで書く。
  全角ギリシャ文字（α β θ）を数式中に混ぜない

> 例外はコードブロック内のみ。実装コードの docstring はプレーンテキスト
> でよいが、その場合も対応する設計書の式番号を参照する
> （例: 「更新式の詳細は設計書の `式 (2)`」）。

## 数式には必ず番号を振る

- 独立した数式（`$$...$$`）には **必ず** `\tag{n}` で番号を付ける
- 番号は **文書ごとに 1 から連番** 。文書をまたいで通し番号にしない
- 本文からは **式 (n)** の形で参照する（例: 「 `式 (3)` より」）
- インライン数式には番号を振らない（参照する必要が出たら独立させる）

```
$$
\mathrm{RMSE} = \sqrt{ \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2 }
\tag{4}
$$
```

## 図・表にも番号を振り、本文から参照する

- 図: **図 n: キャプション** を図の **下** に置く
- 表: **表 n: キャプション** を表の **上** に置く
- 図・表それぞれ文書ごとに 1 から連番（式とは独立した番号系列）
- Mermaid 図も図として番号を振る
- 本文からは **図 n** / **表 n** の形で参照する

## 参照されない図・表・式を残さない

- すべての図・表・番号付き数式は、本文中から **最低 1 回は参照する** 。
  「下図」「次の表」のような相対参照ではなく、必ず番号で参照する
  （文書を編集して順序が変わったときに壊れないため）
- 参照されない図・表・式は、不要か本文の説明が足りないかのどちらか。
  どちらであるかを判断してから、削除するか本文を補う

## 他の文書の図・表・式を参照するとき

番号は文書ごとに独立しているため、 **他文書の番号をそのまま
`式 (1)` の形で書いてはいけない** （自文書の `式 (1)` と区別できず、
検証ツールも「定義の無い参照」として検出する）。

他文書を参照するときは **フェーズ番号を前置する** 。 表 1 に対応を示す。

表 1: 自文書と他文書の参照記法

| 種別 | 自文書 | 他文書 |
|---|---|---|
| 数式 | `式 (1)` | `式 (P01-1)` |
| 図 | `図 1` | `図 P01-1` |
| 表 | `表 1` | `表 P01-1` |

（表 1 の記法例はインラインコードで書いてある。生のまま書くと
検証ツールが「定義の無い参照」として検出してしまうため。）

どの文書かが曖昧になる場合は、文書名も添える
（例: 「P01 要求仕様書の 表 P01-2」）。

## 記号の定義を必ず添える

- 数式を出したら、その直後に **登場する記号の意味と単位** を列挙する
  （表にするのが望ましい）。単位はプロファイルの命名規則と揃える
- 定義済みの記号を同じ文書内で再定義しない。別の意味で使い回さない

## 番号付けの機械検証

数式・図・表を書いたり修正したりしたら、 **必ず番号検証ツールを実行する**
（手作業での目視確認は禁止 —— 番号のズレは見落とすため）。

```
powershell -File .claude/tools/check_numbering.ps1 -Path <file.md>
powershell -File .claude/tools/check_numbering.ps1 -Path docs
```

検出される 4 種（`DUP` / `GAP` / `UNREF` / `DANGL`）の意味は
`SKILL.md` の 表 1 を参照。NG が出たまま作業を完了としない。

範囲参照（ `式 (1)` 〜 `式 (6)` ）は間の番号もすべて参照済みとして扱う。
