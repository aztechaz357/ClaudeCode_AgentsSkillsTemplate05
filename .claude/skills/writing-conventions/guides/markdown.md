# Markdown 本文の記法

## 強調記法の前後に半角スペースを入れる

`**強調**` を使う場合、強調範囲の直前・直後に半角スペースを置く。

```
これは **強調** です
```

日本語文字と `**` が密着すると、レンダラーによっては強調と解釈されない。

- 対象はドキュメントの本文。コードブロック・インラインコード内は対象外

## 見出しと箇条書き

- 見出しは 1 段ずつ下げる（`#` の次は `##`。`###` へ飛ばさない）
- 箇条書きの階層は 3 段まで。それ以上必要なら表か節に分ける
- 表のヘッダ区切りは `|---|` で統一する（桁揃えの空白は入れない）

## コードブロック

- フェンスには言語を書く（ ` ```python ` ` ```powershell ` ` ```mermaid ` ）。
  **出力ブロックだけは言語指定なし** の ` ``` ` にする ——
  マニュアルの例と出力を照合するツールが、言語指定の有無で対を判定するため
- 規約の説明文中にコードブロックで例を書くのは安全。検証ツールは
  コードブロック内を番号の定義として数えない

## 用語と表記

- 用語の定義は `docs/glossary.md` を正とする。同じ概念に複数の呼び名を
  使わない（見つけたら用語集へ寄せる）
- 英語の識別子を本文に出すときは、初出で日本語の意味を併記する
  （ `UserRepository（利用者リポジトリ）` ）
- 物理量には単位を併記する（ `経過時間 dt_s [s]` ）。単位の書式は
  プロファイルの命名規則と揃える

## ファイル書式

- 文字コードは UTF-8。改行コードはリポジトリの `.gitattributes` に従う
- 1 行の長さは目安 80〜100 文字。日本語は折り返し位置を文の切れ目に置く
  （差分が読みやすくなる）
