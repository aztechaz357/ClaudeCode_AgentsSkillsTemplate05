# S## 記入用ワークシート —— 要求（段1）

> **これはあなたが書く用紙です。** Claude は書きません。
> 埋め終わったら `/intake` と打ってください。読みに行って詰めます。
>
> - **全部埋めなくて構いません。** 空欄は「まだ決まっていない」として扱い、
>   候補を出して一緒に決めます
> - **きれいな言葉に直さなくて構いません。** 話し言葉・箇条書き・
>   愚痴のままで十分です（そのほうが後から読んで役に立ちます）
> - `- [ ]` は該当するものに `x` を入れてください（複数可）
> - 各欄の `例:` は消して上書きしてください

---

## 1. 何を作るか

> 一番広い言い方と一番狭い言い方の間のどこを狙うかで、
> このあとの作業量が数倍変わります。

- [ ] **広め** —— 関連する操作をまとめて一通り
- [ ] **ちょうど** —— 今いちばん困っている 1 つだけ
- [ ] **狭め** —— まず手で動かして確かめられる最小の 1 本
- [ ] 上のどれでもない（下に書く）

**やりたいこと（「〜したい」で書いてください）**:

```
例: 手元の CSV の行数を、ファイルを開かずに数えたい
```

---

## 2. なぜ要るか（理由）

> **この用紙で一番大事な欄です。** ここが空だと、以降の成果物が全部
> 「たぶんこうだろう」の上に積み上がります。
> 要求の言い換え（「数える機能が必要だから」）は理由になりません。
> **要求の外側にある事実** —— いつ・何回・どれだけ困ったか —— を書いてください。

- [ ] 毎回手でやっていて時間が溶ける
- [ ] 手でやると間違える
- [ ] 人に頼まれて渡す必要がある
- [ ] 他の作業の前提になっていて、ここで止まる
- [ ] 上のどれでもない（下に書く）

**自由記述（具体的な事実を。回数・時間・失敗した経験）**:

```
例: 月末に 30 個の CSV を目視で数えている。1 時間かかるうえ、
    去年 2 回数え間違えて、後工程に謝りに行った。
```

---

## 3. 入力と出力

> 何を渡すと何が返るか。ここが決まれば、作るものの形はほぼ決まります。
> **「なし」ではなく「引数なし」「画面表示なし」と書いてください**
> （空欄と「無い」を区別するため）。

| | 内容 |
|---|---|
| **入力** | 例: CSV ファイルのパスを 1 つ |
| **出力** | 例: 行数の数字を画面に 1 行 |

---

## 4. うまくいく例と、失敗する例

> **文章より、この 2 行のほうが速く正確に伝わります。**
> 実際にありそうな値で書いてください。

### 正常系（N1）—— うまくいくとき

```
こう渡すと:   例: 3 行入った売上.csv を渡す
こう返ってくる: 例: 画面に 3 と出て、正常終了する
```

### 異常系（E1）—— 失敗するとき

> **ここを空にしないでください。** 空のまま進むと、失敗したときの
> 振る舞いをこちらが勝手に決めることになります。
> 「まだ決めていない」なら、それ自体を下に書いてください（一緒に決めます）。

- [ ] エラーを画面に出して止まる
- [ ] 警告を出して、できるところまで続ける
- [ ] 何も言わずに何もしない
- [ ] まだ決めていない（一緒に決めたい）

```
こう渡すと:   例: 存在しないファイル名を渡す
こう返ってくる: 例: 「ファイルが見つかりません: 売上.csv」と出て止まる
```

---

## 5. 何ができたら「通った」と言えるか

> 完走の条件。ここに書いたものが、そのままテストになります。
> **L1（まず動く）では 1〜3 個で十分です。** 多いとスライスが大きすぎます。

- [ ] 上の正常系（N1）がそのとおり動く
- [ ] 上の異常系（E1）がそのとおり動く
- [ ] 実際の自分のファイルで 1 回動く
- [ ] 他の人に渡して動く

**追加で（あれば）**:

```
例: 1 万行のファイルでも数秒で終わる
```

---

## 6. 今回はやらないこと（非目標）

> **書いておくと、あとで「なぜやっていないのか」を説明しなくて済みます。**
> やらないと決めたことは、失敗ではなく判断です。

```
例: 複数ファイルをまとめて数えるのは今回やらない（まず 1 本通したい）
例: 文字コードの自動判定はやらない（自分のファイルは全部 UTF-8）
```

```
例: 空行を 1 行と数えるべきか迷っている

```
