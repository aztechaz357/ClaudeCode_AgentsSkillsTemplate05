## 2. 外の世界に触るか

> ファイル・DB・ネットワーク・時刻・乱数に触るなら、そこは **契約（Port）**
> で切り離す候補です。切ると、テストのときに本物のファイルを使わずに済みます。
> 切らないと、テストが遅くなり、実行のたびに実ファイルが要ります。

- [ ] ファイルを読む
- [ ] ファイルを書く
- [ ] ネットワークに出る
- [ ] 現在時刻・乱数を使う
- [ ] 外の世界には触らない（計算だけ）

**契約を切りますか**:

- [ ] **切る** —— テストが速くなる。代わりにファイルが 1〜2 本増える
- [ ] **切らない** —— 今回は最短で通したい。テストは実ファイルを使う
- [ ] わからない（決めてほしい）

```
補足があれば: 例: 将来 Excel も読みたくなりそうなので、切っておきたい
```

## 4. うまくいく例と、失敗する例（技術の言葉で）

> 段1 の `N1`・`E1` と **同じケース** を、値の形まで落とします。
> ID は振り直さないでください（要求・設計・テストの対応が切れます）。

### N1（正常系）

```
入力: 例: 売上.csv というファイル（3 行、ヘッダなし）
出力: 例: 画面に 3、終了コード 0
```

### E1（異常系）

> **失敗したときに、例外で落ちてよいか / 結果として返すか** は
> このスライスの性格を決めます。

- [ ] そのまま落ちてよい（まず動かすのが優先）
- [ ] メッセージを出して静かに終わる
- [ ] 呼び出し元に結果として返す（落とさない）
- [ ] わからない（決めてほしい）

```
入力: 例: 存在しないファイル名
出力: 例: 「ファイルが見つかりません: 売上.csv」を画面に、終了コード 2
```
