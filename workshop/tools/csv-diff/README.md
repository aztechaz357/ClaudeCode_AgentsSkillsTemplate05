# csv-diff

2つの CSV を行単位で比べ、片方にしかない行を `-` / `+` で出す。
出力ファイルを差し替えたときに「本当に変わったのはどの行か」を見るために使う。

## 1. 準備

不要（Python 3.12 の標準ライブラリだけで動く）。

## 2. 最小の実行例

```
python main.py before.csv after.csv
```

差分があるとき（終了コード 1）:

```
--- before.csv
+++ after.csv
- 2,bob,20
- 3,carol,41
+ 2,bob,21
+ 4,dave,35
RESULT: 2 removed, 2 added
```

差分が無いとき（終了コード 0）:

```
RESULT: no differences (3 rows)
```

ファイルが無いとき（終了コード 2）:

```
ERROR: file not found: nope.csv
```

## 3. 引数

引数は表 1 のとおり。

表 1: csv-diff の引数

| 引数 | 必須 | 意味 | 既定値 |
|---|---|---|---|
| `left` | はい | 比較元の CSV のパス | なし |
| `right` | はい | 比較先の CSV のパス | なし |

終了コードは 0 = 差分なし / 1 = 差分あり / 2 = ファイルが無い・列構成が違う。

## 4. 落とし穴

実際に踏んだものを表 2 に挙げる。

表 2: csv-diff の落とし穴

| 症状 | 原因 | 対処 |
|---|---|---|
| 値を 1 つ変えただけなのに `- ` と `+ ` の 2 行が出る | 行の集合差として出しているため、変更は「削除 ＋ 追加」になる | 仕様。行の対応を取りたいなら別ツールにする |
| 行の順番を入れ替えただけで差分が出ない | 集合として比べているため順序は見ていない | 順序も見たいなら本開発レーンで作り直す |

## 5. 既知の制限

- 文字コードは UTF-8 固定。Shift_JIS の CSV は読めない
- 区切り文字はカンマ固定（TSV は非対応）
- 行の対応付け（キー列指定）をしないので、変更は削除＋追加として出る
- 全行をメモリに載せる。巨大な CSV は想定していない
